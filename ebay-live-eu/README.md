# eBay Live EU experience concept

A responsive, interactive prototype for a unified cross-border eBay Live experience across all 27 EU markets.

## Journeys

- Seller: registration, EU Live Passport onboarding, pre-show planning, live studio, and post-show fulfillment
- Buyer: discovery, bid preparation, live bidding, and post-purchase tracking
- Experience logic: the eligibility model, viability model, value exchange, and design tenets

The prototype separates hard transaction eligibility from show viability:

`seller × show × item × destination → eligible`

`demand × price × delivery × localization → viable`

## Run locally

```bash
npm install
npm run dev
```

Build and lint:

```bash
npm run build
npm run lint
```
